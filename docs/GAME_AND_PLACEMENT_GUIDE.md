## 1. この指示書の読み方

「確定」はユーザーの指示・原資料の設定。「配置案」は、曖昧な内訳を動かして確認できるよう具体化した初期案。「未定」は確定値を捏造しない項目。
優先順：今回および最新のユーザー指示 → weapon_balance.json等の採用済み数値 → 採用済みモーション仕様 → パワポ → この資料の配置案。
同じ項目で古い会話と数値表が違う場合、最新の数値表を使う。ボスのパワポのジャンプのみ／ミサイル案は古く、採用済みパンチ・マシンガン・踏みつけに置き換える。
素材があることと、当たり判定・AI・ゲーム処理が完成していることを混同しない。GIFは動作確認用で、再生速度やループ設定をそのままゲーム状態にしない。

## 2. ゲーム全体

PC専用ブラウザ、1人用ベルトスクロールアクション。主人公ミカ＋自律支援ロボ。SDキャラ、384×216原寸、整数倍拡大・nearest-neighbor。上下移動と足元yによる奥行きソート、ジャンプ高さは足元と別管理。
ファイナルファイト、D&D、TMNTの操作感、メタルスラッグのギミック感を参考に、ミカ自身の多彩なアクションを主役にする。会話で止めずテンポよく進む。人型の敵でも人間を斬る演出にはせず、モンスター／メカを使う。
ミカはレベル成長なし。成長対象はロボ／NPCのみ（内容・数値は未定）。点数はお金。ルート分岐は構想あり、今回1面はA→B→Cの本線と隠し部屋。

起動→デモ（未作成なので当面省略）→タイトル→ワールドマップ→1面→ワールドマップ→2面→ワールドマップ→3面→ワールドマップ→4面→ワールドマップ→5面→クリア演出→エンディング（リザルト・スコア集計）→タイトル。
ワールドマップは次の攻略地点にアイコンを置いて点滅して移行。クリア済み地域は明るく、未クリア地域は暗い。自由ステージ選択を前提にしない。点滅間隔や表示時間は未定。
2面はモアイ荒野／地下エレベータ／秘密基地、ボス案ダークミカ。3面は妖精の森／雲上／城の構想。3面中ボス案はHP半分のゴブリンロボ2体。2面以降の敵配置・追加素材は本書で確定しない。4・5面は未定。

## 5. HP・ロボ・復帰

残機制はなし。ミカが倒れてロボが生きていれば、ロボが近づき約5秒救命して復帰する案を採用。ロボも壊れていればゲームオーバー。
ロボはキャタピラー移動。ジャンプ・殴りはなく、サブマシンガン中心、ときどきミサイル。壊れると煙・電気・頭に白旗。一定数の敵撃破で修復復帰（撃破数は未定）。救命／復帰の素材あり。
HP最大値、復帰時HP、救命中の被弾・中断・無敵、ロボの攻撃間隔・射程・成長、撃破数のカウント方法は未定。

## 7. マップ・時間・隠し部屋

1ステージ3MAP、1MAPは5戦闘画面。1面はA昼の廃墟商店街→Bビル内店舗街→C夕方の瓦礫街。各MAPの背景は1920×216の1枚の地続きパノラマを連続スクロール。384pxごとに背景を取り替えない。遠景は必要なものだけ採用。
戦闘中はカメラを固定。有限波はキューが空、かつ通常＋固定の敵が全滅したらGO!、次の移動区間へ。本線を後ろへ戻せない。移動中にも指定敵が出る。
各戦闘と移動区間のTIMEは99、4秒で1減る、最大6分36秒。ポーズ中は停止。A/B/Cそれぞれ5戦闘＋4移動＝27区間。区間ごとの残りを保存し、1面クリアで合計×100点を一度だけ加算。カメラ操作・部屋の直接選択ではボーナスを発生させない。
パワポでは時間切れは死亡。そこからロボ救命が可能か即終了かは未定。隠し部屋・救命・暗転中にTIMEを止めるかは未定。既存確認画面は隠し部屋で親タイマーを止めているだけで、最終仕様ではない。

隠し部屋はA_H1→A_H2、B_H1→B_H2、B_H3。入口近くで↑。退出した入口だけ再入場不可。子から親へ戻ることでは親の帰路を塞がない。親の物体・敵・戦利品の状態を維持し、再抽選・再出現しない。
独立した浮いた扉を置かない。左の帰路は壁の開口、右の隠し入口は壁に偽装して発見／破壊後に開口背景へ切替。B_H1右壁は破壊必須。入口発見条件の細部は配置データと採用プレビューを参照。
障害物は原則HP1、破壊で100点＋20%でテーブル1宝箱。宝箱はHP1で中身必ず出る。硬い障害物は別指定。宝箱自身の点数は未定。物体はのけぞらず破壊段階／爆発へ移る。未作成の破壊コマは必要に応じて追加。
必須宝箱：A3テーブル1＋ポーション、A5テーブル1＋ハイポーション、B3テーブル1＋ポーション、B5テーブル2＋ハイポーション、C4テーブル2＋エリクサー。
隠し宝箱：A_H1=1,1,2／A_H2=2,3,4／B_H1=1,1,2,2／B_H2=1,2,2,3／B_H3=1,1,2,2。既存chests.jsonの抽選と中身設定を使う。

## 9. 今回確定した敵配置ルール

通常出現は1シーン計5体、同時生存は最大4体。固定敵は通常5体への追加で、通常の同時4体からも除外する。固定は1回だけ配置し、通常波補充で重複させない。
固定優先：この配分案では固定を先に出し、固定全滅後に通常波を開始する。これは「固定優先」を具体化した案で、固定と通常の同時混在に変えたくなったら開始条件だけ変更できる。通常枠の敵は撃破／退場で空きができたら順番に補充。
固定配置とは初期の待ち位置の指定。戦闘開始後もその場から絶対に動かない敵、という意味ではない。弓兵が待機位置を維持する度合いはAI設定で調整。

A：ゴブリン中心、スケルトン・デスハウンド。
B：ゴブリン中心、スケルトン。終盤にホブゴブリン紫を合計2体程度（案ではB4/B5各1）。
C：ゴブリン・デスハウンド・ホブゴブリン、青オーガを各画面1体程度。案ではC1〜C4各1、ボスC5は例外。黄色ギガース最後に1体は、ボス直前C4の最終枠とする案。
パワポ必須A3マシンガンゴブリン1体、B2兜＋刀ゴブリン1体は通常5体の中に組み込む。A5固定の刀1体とは別。A3固定4体にもマシンガン敵を重複して追加しない。

固定：A3宝箱群の周囲ゴブリン4／A5宝箱群の周囲ゴブリン4、うち刀1／B2・B4バリケード奥に弓ゴブリン各3、画面の上下方向に縦並び／C1バリケード奥にゴブリン4。計18体。
宝箱が2つある場所でも、各宝箱に4体ずつではなく宝箱群を囲む計4体。固定敵が使った武器を落とすかは今回未指定。A3必須マシンガンとB2必須刀は倒すと落とす。
既存B2にはバリケードB_prop_06がある。B4／C1には対応するバリケードがないので追加か移設が必要。今回データでは要求だけ記し、背景・既存配置を勝手に変更していない。原寸座標は未指定でアンカー／陣形から配置する。
「奥」は進行方向の先（ミカが左から近づくなら右側）を案の基準とする。y軸の奥を意味する指示が欲しい場合は「上側」と書く。縦並びはxを揃えて足元yをずらす。歩行範囲から出さない。低いバリケード越しに矢が通るか・回り込めるか・破壊まで通れないかは実戦で決める。

ボスを除く通常区間26×5＝130体、固定18＝有限敵148体。ボス1体と無限補充の雑魚、未指定の隠し部屋敵は含まない。移動も5体の案なので数は多め。移動中を2〜3体へ減らす場合も、移動区間だけ変更できる。
移動の通常敵が残ったまま次画面へ抜ける仕様は未定。本案は次の停止位置まで到達し、キュー空＋全滅で次戦闘へ移る。背景の切替境界とは分けて管理する。

## 10. C5ゴブリンロボ

ギガースより大きい128px相当の白い鉄ロボ。上半身なし、腰の操縦席にゴブリンが乗りレバー操作。遅い歩行、軸と距離が合うと予備動作して攻撃。開幕空から落下しズシーン。
メインは前へ伸びるパンチ8＋吹っ飛び。前方マシンガン10発、各1。時々ジャンプ踏みつけ10＋吹っ飛び。ボスが吹っ飛んで倒れたら起き上がりジャンプまで無敵。無敵の厳密な終了フレームは未定。
HP25%未満で赤点滅。撃破で長い爆発、瓦礫になり操縦ゴブリンが落ちて倒れる。HP／撃破点／補充間隔は未定。
C5は通常5体の例外。最弱・素手ゴブリンを最大3体まで補充、ボスは数に含めない。ボス撃破で補充停止し進行。残る雑魚の退場方法は未定。ギガースはC4案なのでC5の補充枠に紛れ込ませない。
後半の色違い雑魚版は同じ素材と別ステータスで再利用可能、具体配色・HP・行動・登場数は別指定。

## 11. らりくんから配置変更を出す書式

CSVを書かなくても日本語の指示でよい。こちら／ClaudeがIDとデータへ変換する。最低限「面、MAP、画面か移動、通常か固定、敵、数」。武器、色、登場位置、順番、落とす物は必要な時だけ。

例1：『1面A2、通常5体をゴブリン3・スケルトン1・ハウンド1に変更。順番はお任せ。上限4はそのまま』
例2：『1面B2、固定の弓ゴブリン3体はバリケードの右に縦並び。倒しても弓は落とさない』
例3：『1面C3→C4の移動はゴブリン2とハウンド1、計3体に変更』
例4：『A5の固定刀ゴブリンだけ紫へ変更、刀は落とす。通常波の5体は変更しない』

| 指定する項目 | 書き方 | 省略時の扱い |
| --- | --- | --- |
| 区間 | A3、A3→A4移動（ID A3_travel） | 区間だけは必須 |
| 種別 | 通常／固定／ボス補充 | 不明なら文脈を確認、勝手に混同しない |
| 内訳 | ゴブリン3、スケルトン2 | 通常合計5、変更指示があれば新しい合計 |
| 武器・色 | ホブ紫＋刀、青オーガ＋斧 | 通常色・武器なし。スケルトンは固有剣盾 |
| 順番 | 1ゴブリン、2ハウンド…／お任せ | この配置案の順番、再抽選しない |
| 位置 | 左／右から、上／中／下、宝箱周囲 | 配置案。固定はアンカー位置を基準 |
| 開始条件 | 画面開始／近づいたら／固定全滅後 | 固定優先の案を維持 |
| ドロップ | 刀を落とす／落とさない | 必須武器だけ確定、他は未定を保持 |

数字で置きたい時：xはMAP内ワールド座標、yは足元。MAPごとにxを0から始める。戦闘n画面のローカルxに384×(n−1)を足す。左右反転で向きを変え、フレームごとにサイズを変えない。移動区間はカメラ追従中の出現位置を別管理。
宝箱群の周囲やバリケード奥などの陣形は、基準物体ID＋人数＋陣形で指示できる。今回は座標を未定(null)で残し、原寸歩行範囲・敵幅・射線を見て置く。

## 12. 同梱ファイル・編集の正本

ENEMY_PLACEMENT_AND_CATALOG.xlsx：全モンスター、装備候補63行、武器数値、27区間、通常敵130行、固定18行、指示テンプレート、未定事項。人が見て編集する一覧。
stage1_enemy_placement.json：本書の配置案の機械用正本。各CSVは同内容の交換用。CSV／Excelを直したらJSONへ反映して版を更新し、複数を同時に別々の正本として扱わない。既存のゲーム／配置ビューアに自動取り込み機能があるわけではない。
section_idはA1…C5、A1_travel…C4_travel。enemy_idは一覧のID、weapon_idは一覧のID。quantity=1の行を順に実行する。空欄は未定で0に変換しない。CSVのTrue/Falseは文字列の真偽変換が必要。Noneは空欄。JSONはtrue/false/nullを用いる。
各シーンは同時生存数を計測する。wave_totalは配置総数、wave_max_aliveは同時上限、fixedは双方から除外。orderは区間内の順番。補充敵に有限のquantityを与えない。
未確定データは本番で適当な値を固定せず、テスト用値を設定ファイルへ分離し、仮値と明記して調整できるようにする。
referenceフォルダの設定はv116の変更していないコピー。最新版の本体素材ZIPを別途一緒にClaudeへ渡す。画像を再生成せず、animation.jsonの原点・フレーム・durationを利用する。ヒットボックスは新たに定義。

## 13. Claudeへの実装依頼・完了条件

まず1面A1の縦移動・ジャンプ・6段コンボ・ヒットストップ・被ダメージ無敵・ゴブリン・ロボ支援を実際に操作できるようにする。次に武器／固定敵／移動区間／隠し部屋／ボス／TIME集計、最後にタイトル・ワールドマップ・リザルトへ接続。未作成の2〜5面を勝手に完成扱いにしない。

- 通常5体が一度に5体出ず、同時4以下、撃破で次を補充。キュー空だけではGOにしない。
- 固定18体と必須武器敵を二重出現させない。A5固定刀とB2兜刀を両方用意する。
- 本案の固定先行を守る。後から混在設定にしても固定を通常枠の数へ混ぜない。
- B4/C1のバリケード追加／移設を行い、固定敵が壁の中・歩行範囲外に置かれない。
- C5通常波は無効、ボス＋最大3補充雑魚。ボス撃破で補充停止、終了が無限に待たされない。
- 装備中もスライディングでき、刀以外のAを素手コンボに戻さない。刀のゴブリン等、素材不足を報告して補う。
- 背景が地続き、足元ソートと空中高さが分離、反転で武器の持ち手を統一できる。
- 隠し部屋の親状態、帰路、一度きりフラグ、戦利品が保持される。
- TIMEは4秒刻み、ポーズ中停止。残り時間とボーナスを二重集計しない。
- ミカとロボのHP、破損・救命・復帰・ゲームオーバーの状態を分離する。
- HUDは背景に直接重ね、攻撃対象情報とロボ情報を混同しない。
- 得点アイテム／金貨／武器の拾い処理と、マップ切替時の消滅・破棄を区別する。
