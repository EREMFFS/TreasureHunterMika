## 4. HP・AI・武器の数値（data/tuning.js ほか）
- 雑魚HP = 切り上げ(基本HP × 面倍率)、面倍率 1.0 / 1.1 / 1.2（ボスには掛けない）。攻撃待ち倍率 1.0 / 0.95 / 0.9（AIの待ち時間だけ）。基本HPは既存の上書き値（ゴブリン14・ホブ18・デス22・スケルトン18）と敵一覧の値。
- ボス: ゴブリンメカ120（3Aは半分の60×2）、ダークミカ140（50%で後半）、クイーン180（50%で後半）。取り巻き: メカ＝ゴブリン常時3体（1面のみ無限）、ダークミカ＝メガゴブリン同時2・計6・3秒間隔、クイーン＝紫中心・赤少し 同時2・計6・3秒間隔（雷の予告中は取り巻きが攻撃しない）。
- ボスの攻撃: メカ パンチ8・SMG10発各1・踏み10・25%未満で赤点滅・転倒〜起き上がりジャンプ無敵。ダークミカ 刀5（敵の刀）・素手2〜3・後半SMG各2・ランチャー20（既存の敵用威力）。クイーン 炎8（頭の高さz30・三方向、スライディング／ジャンプで回避）・雷15（予告700ms、予告開始時の足元、影の中ならジャンプしても当たる）。
- ミカの武器: 敵一覧の「既に決まった武器値」を優先（刀2・約50回、SMG1・撃っている間だけ10秒、ランチャー10・5発、斧8＋地割れ5・10回、火炎1/0.1秒・10秒、波動砲20・1発）。弓・グングニル・ハンマー・ロケットパンチは weapon_balance.json の値。A＝武器攻撃、ダッシュ中↓A＝スライディングは維持、空中Aは各武器の空中攻撃。マップ移動で武器は捨てる（weapon_balance.json）。隠し部屋の出入りと3Aの森の段の移動では持ち越す。
- 仮の撃破点: ゴブリンメカ10000、ダークミカ20000、クイーン30000、3Aのメカ各5000、メガゴブリン200・メガメガ200。

## 6. 提案から変えた点・解釈
- 移動区間の敵数: 1面の既存データ（各5体）を、指針の「息抜き」に合わせて3体前後に減らしました。
- 3A P05/P06: 既存layoutのまま（P05はF3-4→F3-2、P06はF2-5→F3-3）。小道は「その画面を全滅させてから」使えます。森の段は横に戻れないので、通り過ぎた小道は使えません。
- 3Aの森の各段の終端は行き止まり。段の最後まで来たら奥の小道（看板付き）で別の段へ。
- 隠し部屋の中はTIMEを止めています（timer_policy が未定のため）。
- 移動区間中でも、その場に敵がいなければ隠し入口へ入れます（出現待ちはスクロールで出てくるため）。
- 雑魚が画面の外から殴らないよう、立ち位置が画面外なら反対側へ回り込むようにしました。持ち場の弓兵が画面外へ飛ばされた時は持ち場を捨てて戻ります。
