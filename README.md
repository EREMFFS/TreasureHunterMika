# TREASURE HUNTER MIKA（トレジャーハンターミカ／ゴブリン族の秘宝）　v0.5（1〜3面）

素材：MIKA_ANIMATION_v116 ＋ v117・v118 差分 ＋ 斬風 v001 ＋ MIKA_TODAY_HANDOFF_20261007 ＋ MIKA_STAGE123_IMPLEMENTATION_20261007 ＋ 効果音（ミカ基本・ジャンプ・ダッシュ）

`index.html` をブラウザ（Chrome推奨）で開くと動きます。サーバー不要、ダブルクリックで起動できます。
1〜3面の詳しい確認結果・採用値・不足素材は `docs/STAGE123_REPORT.md` にあります。

## 操作
| キー | 動作 |
| --- | --- |
| 方向キー | 歩く・上下の軸ずらし |
| 横2回 | ダッシュ |
| Z（またはJ） | A：攻撃（武器を持っていれば武器。銃・火炎放射は押している間） |
| X（またはK） | B：ジャンプ |
| ↑ | 隠し入口・奥の小道・出口の扉に入る |
| Enter | スタート |
| P / Esc | ポーズ |
| F2 | 当たり判定の表示切替（確認用） |

- 静止してAを当て続ける → パンチ→右キック→左キック→強パンチ→回転肘→スクリューアッパー（SMASH!）
- ↑を押しながらA：回転蹴り　↓を押しながらA：足払い
- ジャンプ中A：ジャンプ蹴り　ダッシュ中A：タックル　ダッシュ中↓＋A：スライディング
- Aを押し続ける：手招き挑発（敵を呼び寄せる）
- 敵へ正面から歩いて密着：掴み → A：膝×3→アッパー／方向＋A：背負い投げ（投げた敵が他の敵を巻き込む）

## 流れ
タイトル → ワールドマップ → 1面（A→B→C、ボス：ゴブリンメカ）→ 2面（A→地下エレベーター→研究所、ボス：ダークミカ）→ 3面（マヨイの森の分岐→雲の上→妖精の城、ボス：ゴブリンクイーン→命乞い→右へ退場）→ ワールドマップ4（未実装表示）。
各マップの最初はミカとロボが左から歩いて登場。武器は落ちている物の上でAで拾い、Aが武器の攻撃に置き換わります（1枠・マップ移動で捨てる）。

確認用のURL（公開ページでは末尾の # の方）:
- `#s2` `#s3` … 2面・3面から　`#2B` `#2C` `#3F3` `#3B` `#3C` … そのマップから
- `#boss` `#boss2` `#boss3` … 各ボス戦から　`#mini` … 3A終端のメカ2体から
- `?skip=1` タイトルとマップを飛ばす / `?map=2B&section=EB3` 区間を指定 / `?hitbox=1` 当たり判定表示（F2キーでも切替）

## 敵配置の直し方
1. 日本語で指示（例：「2面C3、メガゴブリン3体の群れのあとメガメガ1体」）→ こちらで正本JSONを更新します。
2. CSVで直す場合：`data/csv/stageN_waves.csv` 等を編集 → `python3 tools/build_data.py from-csv N`（正本JSONへ取り込み、versionが1つ上がります）。
   group＝群れの番号、spawn_when_alive_le＝前の群れの残りがこの数以下になったら出てくる。
   正本はJSONひとつだけで、CSVは毎回JSONから作り直されます。

## 素材の圧縮
`python3 tools/build_assets.py <素材フォルダ（v116にv117・v118差分を重ねたもの）> . <STAGE123の modules フォルダ>`（アニメ定義だけ直す時は末尾に `--anims-only`）
使うコマだけを透明余白を切り詰めて2枚のアトラスに詰め、ロスレスWebP化しています（約300MB → 約5.4MB）。
アトラスは data/atlas_pages.js に埋め込み（file:// でも色違いのパレット変換が動くため）。
切り詰めた位置は記録しているので、原寸・足元原点・コマごとのキャンバスサイズはそのままです。
同じ絵の背景は自動で1ファイルにまとめます。

## v0.5.3（2026-10-08）手応え・見やすさ
- 区間（非ボス）の最後の1体を倒すと軽いスロー（0.3倍・0.55秒）＋揺れ。`T.stage.lastKill*`

- TIME はマップ（1A・1B…、3F1〜3は3Aとしてまとめる）ごと。初期600秒・基本切れない。マップ終了時の残り秒×500点をステージクリア時に加算。`T.mapTime`
- 武器アイコンと残数をミカの頭上に表示（残り少ないと赤点滅）。画面左上の武器枠は廃止。
- クイーンの火炎は小よろけ扱い。
